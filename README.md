what it does: 

It's a tool for logging how long you study each subject. You can either start a live timer (press Enter to begin, press Enter again when you stop) or manually type in how many minutes you studied. It then shows you stats — like total time per subject, how many sessions you've done, and your average session length.

why the database matters: 

Unlike a simple script that forgets everything once it closes, this tool saves every session to a real database file on your computer. That means you can close the program, come back a week later, and all your previous study data is still there — building up a genuine long-term record instead of starting from zero each time.

how to run it: 

Someone runs python3 study_tracker.py in a terminal, then picks from a menu — start a timer, log manually, view sessions, or view totals.

why you built it: 

You wanted a second project to pair with your cyber security-focused password checker, this time showing a different skill — working with a real database rather than just an API. It's also genuinely useful to you, since you can actually use it to track your own A-Level revision.
